打开网站

1 · 选择照片

支持索尼 .HIF、iPhone .HEIC，以及 JPEG / PNG / TIFF。原始文件不会被上传到网上，只在本机处理。

    画质

    2 · 检查与命名

    取消勾选不想发布的照片。如果有照片方向不对，用照片上的旋转按钮修正。

    仓库是公开的，打开位置意味着精确坐标会公开可见。在家里或其他私人场所拍的照片建议保持关闭。

    管理

    删除相册可以释放空间。仓库用的是单提交的 gallery 分支，所以删掉的照片不会留在 git 历史里。

    相册日期张数占用
    站点设置

    口令只以 SHA-256 哈希的形式存进 config.json。这是一道软门禁：能挡住路人和搜索引擎，挡不住会看源码的人。
